# Estate

A modern real estate website focused on presenting properties through a clean and responsive frontend experience.

The project explores modern property presentation, structured layouts, and responsive browsing across different screen sizes.

## Live Demo

https://estate-ha.vercel.app/

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS

## Highlights

- Real estate-focused interface
- Property presentation
- Responsive layouts
- Structured content sections
- Modern navigation and page structure
- Responsive experience across devices

## Development Focus

The project focuses on creating a clean browsing experience for property-related content while maintaining:

- Clear information hierarchy
- Responsive behavior
- Consistent UI
- Reusable frontend structure
- Easy navigation
